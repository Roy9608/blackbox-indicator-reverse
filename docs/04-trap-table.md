# 04 · 七大陷阱速查表

排查"对不上"时按此表对号入座。**按"排查成本从低到高"的顺序使用**：
先做便宜检查，再做贵检查。

| # | 陷阱 | 典型症状 | 对策 | Lab |
|---|---|---|---|---|
| 1 | **系数错误** | 数值差整数倍（×2、×10、×0.001） | 做 Step 4 无参数基线 | lab1 |
| 2 | **单笔 vs 聚合** | 零触发 / 量级完全不对 | 检查是否需按窗口聚合再分档 | lab2, lab3 |
| 3 | **静态 vs 动态阈值** | 某些窗口误差特别大，另一些窗口接近 0 | 观察误差是否随窗口系统性变化（缩放因子法，见 05） | lab3 |
| 4 | **时间戳错位** | 整列平移一格（第 N 桶 == 原始第 N−1 桶） | 检查 bisect 方向（铁律 4） | lab2, lab3 |
| 5 | **未收盘数据** | 最新一根的数值持续变化 | 只用已收盘的桶 | lab3 边界 |
| 6 | **单位混淆** | 差价格倍数（base 量 vs quote 额） | 确认每个字段到底是币量还是金额 | lab1 语义层 |
| 7 | **窗口边界** | 短窗口误差大、长窗口误差小 | 截图时刻非整点导致截断——**属正常**，先对齐窗口再看 | lab3 |

## 使用方式：三个诊断问题

拿到一张对账表后，依次问：

### Q1：残差有没有结构？

- 完全随机散点 → 回到铁律 1（数据源）或找自己的 bug
- **恒定比值** → 陷阱 1（乘性因子）
- **只在特定值上出现**（且是"漂亮数"） → 陷阱 4 或边界约定（lab2）
- **只在小窗口出现** → 陷阱 3 或 7

### Q2：残差会不会抵消？

- 总量对、分项错 → 结构性归属错误，比总量错**更危险**
  （它通过总量验收，污染所有下游分项分析）

### Q3：换个窗口还成立吗？

- 成立（独立样本） → 参数可靠
- 不成立 → 陷阱 3，或扫描欠定（lab3 歧义桶）

## 一个容易被忽略的事实

**残差小 ≠ 接近正确。** lab3 中静态 T=500 距离目标只有 1.4%，
但它是错误的口径，换一个窗口立刻劣化。
可接受的验收标准只有一条：**独立样本上逐点为 0**。

"差不多"不是这们手艺的选项——因为口径错误不是噪声，
**它不会在更多数据里平均掉**。
