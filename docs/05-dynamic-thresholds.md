# 05 · 动态口径：最难的一类，与它的边界

静态口径（固定阈值、固定档位）是"死"的——扫一遍参数总能锁定。
**动态口径会随时间变**，你面对的不是一个参数，是一条随时间演化的曲线。

真实案例预告：币安「资金流向」的 30 分钟窗口，**至今没有被完整复现**
（`07-real-case.md`）。本文讲：怎么判断动态、怎么攻击动态、
以及什么时候必须承认攻不动。

## 一、判断"阈值是不是动态"：缩放因子法

**核心思路**：如果阈值固定，各档位随窗口放大的倍数应 ≈ 窗口放大倍数。

```
窗口从 30分 → 1天，放大 48 倍

若阈值固定：各档位都应放大约 48 倍
实测：最小档放大 127.6 倍（超额）、最大档只放大 91.4 倍（不足）
⇒ 阈值随窗口动态调整
```

原理：小阈值只截到小额单——窗口放大时小额单的数量按时间线性增长；
大阈值截到大额单——大额单总量有限，增长必然低于线性。
**超额/不足的不均匀放大 = 阈值在随窗口变。**

另一个更常用的信号（lab3 任务 2 用的就是它）：

```
同锚点、不同窗口，各自 best-fit 静态 T 不一致
→ 阈值不可能是常数
```

还有一个被动信号：**长窗口误差小、短窗口误差大** →
阈值与"近期活跃度"相关（短窗口更敏感地暴露阈值变化）。

## 二、攻击动态口径的三个手段

### 手段 1：切最细粒度

把目标窗口切到系统提供的最细档（lab3 里是 15m），
逐段反推参数，把"一条曲线"离散成"若干个点"。

**边界**：如果真实系统的刷新周期**比最细窗口还短**
（真实币安疑似如此），这条路会断——你永远看到一个混合体。
这是真实案例未解的直接原因之一。

### 手段 2：先验约束

从离散点上读结构，用"常识先验"收窄假设空间：

- **取整粒度**：T 全是 50 的倍数 → 取整到 50
- **下限/上限**：T 有 floor（lab3 是 100）
- **刷新周期**：T 只在特定边界跳变（lab3 是 15 分钟）
- **连续性**：相邻点的 T 不会跳到天边（台阶 vs 抖动）

### 手段 3：收敛约束（参数难锁定时）

找一个**在多个窗口都稳定**的比例作为锚点：

```
某档位占总量比例 = 60~70%（在 30分 到 1天 的所有窗口上都稳定）
→ 可作为参数搜索的约束条件
```

单一窗口欠定时（lab3 的歧义桶 [200, 250, 300, 350]），
**多窗口联合 + 先验合取**才是唯一化之路。

## 三、诚实边界：什么时候承认未解

以下任一情况出现，正确做法是**公开标注未解**，而不是硬凑：

1. 最细窗口内仍混有多次口径切换（分辨率不足）；
2. 数据源拿不全（你只有自己的成交流，算不了全市场 P90）；
3. 残差呈现多参数耦合（如：买方向已复现到 0，卖方向恒差 21~34%
   ——真实案例里就有这个现象，提示存在未观测的第二参数）。

**"已复现 80%"不是复现。** 分方向、分窗口写清楚：
哪些逐点为 0，哪些误差多少，哪些未解——
这是 `06-reporting.md` 输出规范的核心要求。

## 四、lab3 与真实案例的难度对照

| | lab3（可解版） | 真实币安 30 分窗口 |
|---|---|---|
| 规则存在性 | 存在且唯一（我们藏的） | 存在（系统真实在算） |
| 最细粒度 | 15m，恰为刷新周期 | 疑似刷新 < 最细窗口 |
| 数据源 | 完整逐笔（合成） | 只有自己抓的成交流 |
| 参数个数 | 1 个动态阈值 | 疑似 ≥2（方向修正未解） |
| 结果 | 逐点 0 | 长窗口 0.1~4.2%，30 分窗 13.2% 未解 |

做 lab3 的意义：把"动态口径完整还原"的全流程走一遍之后，
你会精确地知道真实案例**卡在哪一步**——以及"未解"两字的分量。
