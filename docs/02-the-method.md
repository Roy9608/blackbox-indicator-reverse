# 02 · 六步法：从"对不上"到"已复现"

这是一套可复用的操作流程。三个 lab 都能用它走通。
每一步给出：做什么 / 为什么 / 产出物。

```
Step 1 锚点样本 → Step 2 时间校准 → Step 3 数据源对账
→ Step 4 无参数基线 → Step 5 参数扫描 → Step 6 交叉验证
```

## Step 1 · 获取锚点样本

**做什么**：拿到尽可能多的"目标值 + 时间戳"。界面上能点的都点：
多窗口档位（15m / 1h / 4h / 1d）、多时段、ⓘ 说明图标。

**为什么**：一组约束只能拟合无限多种口径；**多组约束才能锁定参数**。
ⓘ 图标里偶尔藏着半句真话（lab1 的"≥4000"就是它给的）。

**产出物**：一张记录表：时刻 / 窗口 / 显示值 / 界面原话。

**Lab 对应**：lab1 任务 2（三窗口起步）。

## Step 2 · 时间校准（不可跳过）

**做什么**：用界面上的**价格**与自有数据源同刻价格比对。
价格是最可靠的锚——它显示在明面上，且对时间敏感。

```
卡片"最新价 99.09"  vs  trades.csv 中 21:00 前最后一笔 99.09  → ✓ 可信
```

**为什么**：截图时刻 ≠ 数据时刻（刷新延迟、窗口边界）。
时间轴不齐，后面所有分析都在解噪声。

**产出物**：一个结论："时间轴可信"或"存在 Δt 偏移 = ..."。

## Step 3 · 数据源对账

**做什么**：拿你的原始数据与官方**聚合数据**（如 K 线成交量）逐分钟比对。

```
逐分钟差异恒为 0.0000 → 数据源相同 → 差异必然来自算法
逐分钟差异不为 0      → 先修数据抓取，算法分析毫无意义
```

**为什么**：这是铁律 1。数据源不同时，任何口径分析都是空中楼阁。

**产出物**：逐分钟差异表 + "数据源一致"结论。

**Lab 对应**：lab1 任务 1（加总档 12/12 全对 = 数据源无罪）。

## Step 4 · 先复现"无参数指标"

**做什么**：从不含未知参数的指标入手（如"加总净流入"），
验证公式、正负号、单位。

**为什么**：这一步能暴露**系数错误、字段用错、单位错误**——
它们与"未知参数"无关，混在一起排查会把简单问题复杂化。
分层排查：先确定"框架对了"，再找"参数是什么"。

**产出物**：无参数指标的逐点对账表（目标 = 复现到 0）。

**Lab 对应**：lab1 任务 1；lab3 中"加总净流入"同样是免费的锚。

## Step 5 · 参数扫描

**做什么**：对含未知参数的指标，扫描候选值找误差最小者。

```python
for T in candidate_thresholds:          # 100, 250, 300, ... 20000
    calc = sum(x for x in data if x.quote >= T)
    err = abs(calc - target)
```

**两个必须知道的坑**：

1. **"误差最小" ≠ "口径正确"**。lab3 里 T=500 误差只有 1.4%，
   但它就是错的。接受标准必须是**逐点为 0**，不是"差不多"。
2. **单窗口可能欠定**：多个 T 给出同一结果（lab3 的 14:30 桶）。
   多窗口联合 + 取整粒度等先验，才能唯一化。

**产出物**：候选参数的误差表；能精确匹配的参数集合。

## Step 6 · 独立样本交叉验证

**做什么**：把反推出的公式**当作预测器**，去算没有参与反推的新窗口；
预测值与目标值逐点比对。

**为什么**：扫描是拟合，预测才是验证。在拟合样本上"误差 0"
毫无意义；在独立样本上仍为 0，参数才可靠。

**产出物**：held-out 窗口对账表（lab3 中：两个新 1h 窗口，差 +0.00）。

## 一张图记住全流程

```
锚点样本(多窗口)
   │
   ├─ 价格校准 ──→ 时间轴可信？
   │
   ├─ 逐分钟对账 ─→ 数据源一致？
   │
   ├─ 无参数基线 ─→ 框架正确？(加总=0)
   │
   ├─ 参数扫描 ──→ 精确匹配集合(注意欠定)
   │
   └─ 独立验证 ──→ 逐点为 0 才算复现
```

卡住时回到这张图：**你停在哪一步，就去修哪一步，
不要跳步，不要用后面的步骤掩盖前面的欠账。**
