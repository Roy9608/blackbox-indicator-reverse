# 01 · 当两个数对不上

## 场景

你对接了一个外部系统——交易所 App 的「资金流向分析」、券商软件的
「主力资金」、某个数据平台的衍生指标。你用自己的逐笔数据复现它，
然后发现：

```
App 显示:  大单净流入  -6,392.77
你算的:    大单净流入  -10,000.00
```

差 3,607.23。这时你有四种选择：

1. **"App 错了。"** —— 最省事，最危险。
2. **调参数直到碰上一个接近的数**，宣布复现成功。 —— 更危险，
   因为它带着"我已经对过账"的错觉。
3. **不玩了。** —— 放弃了一个本来可以拿到的信息优势。
4. **把它当成一道可以解的题。** —— 本仓库的全部内容。

## "对不上"只有四种根源

| 根源 | 典型症状 | 排查成本 |
|---|---|---|
| **数据源不同** | 差异到处都是、无规律 | 低（对一次就知道） |
| **时间错位** | 差异随窗口边界系统性变化；整列平移 | 低 |
| **口径不同** | 差异有稳定结构（恒定比值 / 只在边界出现 / 只在特定窗口出现） | 中——这正是反推的对象 |
| **你错了**（bug） | 什么形态都可能出现 | 先于一切排查 |

注意：**前两种是"地基"问题**。数据源没对齐、时间没校准之前，
讨论口径毫无意义——你解的是噪声。

## 为什么值得认真对待

"差不多"的资金流向数据，下游全是暗坑：

- 拿它做策略信号 → 信号含义和你以为的完全不同
- 拿它做报表 → 数字无法与官方对账，公信力归零
- 拿它做归因 → 你在解释一个不存在的现象

一个真实数字：某公式漏掉一个系数 2，数值整整差一倍，
**连续 3 个版本没人发现**——因为从来没有人把自算值和目标值
并排放进同一张表里看过。详见 `07-real-case.md`。

## 本仓库怎么练

三个实验室，共用同一份 48 小时合成数据，难度递进：

| Lab | 黑盒口径的秘密 | 对应的失效模式 |
|---|---|---|
| [lab1](../labs/lab1-static-threshold/worksheet.md) | 隐藏乘性因子（×2） | 阈值公开，口径仍不公开 |
| [lab2](../labs/lab2-aggregation-tiers/worksheet.md) | 边界归属约定 [a,b) | 文档写了范围，没写边界 |
| [lab3](../labs/lab3-dynamic-threshold/worksheet.md) | 动态阈值（随时间重算） | 文档什么都不写 |

三个 lab 的解法共用同一套流程——`02-the-method.md` 的六步。
**变的是黑盒的口径，不变的是你的方法。**

## 先记住一条

**对不上 ≠ 有人错了。** 差异本身是信息：它的**形态**
（恒定比值？只在边界？只在短窗口？）指向具体的根源。
读差异的能力，就是本仓库要教的能力。
