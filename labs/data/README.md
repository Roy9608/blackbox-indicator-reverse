# 数据说明

`trades.csv` 是**合成数据**，不是任何真实交易所的市场数据。
由同目录的 `generate_trades.py` 生成，随机种子固定（20260920），
任何人重新运行得到逐字节相同的结果。

## 生成参数

| 项 | 值 |
|---|---|
| 时间跨度 | 2026-09-18 00:00 → 2026-09-20 00:00（48 小时，数据集内部时间，无时区语义） |
| 成交频率 | 每分钟 3–8 笔 |
| 价格 | 随机游走，每分钟一步 σ=0.0006 |
| 单笔金额 quote | 对数正态 exp(N(3.5, 1.6))，截断到 [10, 80000] USDT |
| 鲸鱼单 | 0.5% 概率 ×8 |
| 边界成交 | 另埋 45 笔恰好等于 1000 / 3000 / 10000 USDT（供 lab2 使用，生成器公开可查） |

## 列定义

| 列 | 含义 |
|---|---|
| timestamp | `YYYY-MM-DD HH:MM:SS.mmm`（毫秒） |
| side | `buy` / `sell`（主动方向） |
| price | 成交价，2 位小数 |
| qty | 数量 = quote / price，6 位小数 |
| quote | 成交额 USDT，2 位小数 |

## 复现

```bash
python generate_trades.py
# trades=15793, >=4000 USDT: 37, planted boundary: 45
# price range: 96.48 .. 102.8
```

三个实验室共用这份数据——变的是黑盒口径，不变的是你的方法。
