## 任务 1：按你的直觉实现四档 (15 分钟)

用你最顺手的方式把每笔成交分进四档，分别加总。两个候选写法：

```python
# 写法 A
if q < 1000: tier = 0
elif q <= 3000: tier = 1      # 注意这些 <= / < 是随手写的
elif q <= 10000: tier = 2
else: tier = 3

# 写法 B（bisect）
import bisect
tier = bisect.bisect_right([1000, 3000, 10000], q)
```

跟 App 对账一个窗口。对上了吗？
