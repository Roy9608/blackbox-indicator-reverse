# Lab 1 —— 静态阈值档：加总对得上，大单翻了一倍

> 难度：★☆☆　|　前置：无　|　预计 30–60 分钟
> 做完再看 `solution/solution.md`。`params.lock` 解码 = 作弊。

## 剧情设定

某交易所 App 有个「资金流向分析」面板。你抓到了它的逐笔成交数据
（`labs/data/trades.csv`），想自己复现面板上的数值。

App 的 ⓘ 帮助里写明：

> 大单：单笔 ≥ 4,000 USDT

**阈值是公开的**。按理说，这道题不该有任何悬念。

## 第 0 步：认识黑盒

```bash
python mystery.py 1h "2026-09-18 20:00"
```

你会得到一张 App 风格的卡片（这是真实运行输出）：

```
==============================================================
 资金流向分析 · SIM/USDT            （模拟教学数据）
 窗口: 2026-09-18 20:00 ~ 2026-09-18 21:00  (1h)
--------------------------------------------------------------
 加总净流入              +32,912.65 USDT
 大单净流入              +64,541.08 USDT
                    [大单: 单笔 >= 4,000 USDT]
--------------------------------------------------------------
 成交笔数                       321
 最新价                       99.09
==============================================================
```

## 任务 1：复现「加总净流入」(10 分钟)

加总 = Σ(+quote 买单 / −quote 卖单)，窗口 [20:00, 21:00)。

自己写十几行 Python（只用标准库），算出来，跟卡片对账。

- [ ] 对上了 → 记下这个事实：**数据源、时间轴、正负号约定全部一致**
- [ ] 对不上 → 先修这里，别碰大单（这是铁律 1）

## 任务 2：复现「大单净流入」(20 分钟)

阈值已知：quote ≥ 4000。把你的大单净流入跟卡片比对，填表：

| 窗口 (1h) | App 大单净流入 | 你的自算值 | 残差 | 残差 / 自算值 |
|---|---|---|---|---|
| 09-18 20:00 | +64,541.08 | | | |
| 09-18 21:00 | （自己跑） | | | |
| 09-19 02:00 | （自己跑） | | | |

三个窗口够了。**看着残差，回答：它是随机的，还是有结构的？**

## 任务 3：全量对账 (20 分钟)

把 48 小时切成 12 个 4h 窗口，逐一对账（App 用 `python mystery.py 4h "..."`）：

| 窗口 (4h) | App | 自算 | 比值 App/自算 | 大单笔数 |
|---|---|---|---|---|
| 09-18 00:00 | | | | |
| 09-18 04:00 | | | | |
| …… | | | | |

## 任务 4：写结论 (10 分钟)

用一句话写下你反推出的**行为**。然后回答两个问题：

1. 这个系数**在数学上**等价于哪几类实现？（至少想出两种）
2. 你能**证明**是其中哪一种吗？如果不能，你的报告应该怎么写？

> 这一步是本 lab 的真正考点：反推能锁定**行为**，不一定能锁定**意图**。
> 报告规范见 `docs/06-reporting.md`。
