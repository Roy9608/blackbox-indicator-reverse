# Lab 3 —— 动态阈值：没有公开口径的大单

> 难度：★★★　|　前置：建议先做 lab1　|　预计 60–90 分钟
> 做完再看 `solution/solution.md`。`params.lock` 解码 = 作弊。

## 剧情设定

还是那个 App。这次它的 ⓘ 帮助里只有一句：

> 大单口径会随市场情况调整。

**没有阈值，没有公式，没有档位表。** 你只有卡片数值和逐笔成交
（`labs/data/trades.csv`）。

这是真实世界最难的形态：真实币安「资金流向」的 30 分钟窗口
至今没有被完整复现（详见 `docs/05-dynamic-thresholds.md`、
`docs/07-real-case.md`）。本题是**可解版**——规则被我们藏进了黑盒，
你有机会把它完整挖出来，体会每一步方法论为什么存在。

## 第 0 步：认识黑盒

## 任务 1：证明"静态阈值救不了" (15 分钟)

对同一个 1h 窗口，扫一遍候选阈值，记录误差：

| 4000 | | −6,392.77 | |

**观察哪一格最危险**（提示：最接近 0 的那一格）。

## 任务 2：缩放信号——阈值不可能是常数 (20 分钟)

固定锚点 12:00，分别跑 15m / 1h / 4h 三个窗口，
对每个窗口找"最接近 App 的静态 T"：

| 窗口 | App 大单净流入 | best-fit T | 误差 |
|---|---|---|---|
| 15m | | | |
| 1h | | | |
| 4h | | | |

如果阈值是常数，三个窗口的 best-fit T 应该相同。
**它们相同吗？** 这就是判断动态口径的"缩放因子法"
（`docs/05-dynamic-thresholds.md`）。

## 任务 3：切细粒度，反推每个 15 分钟的阈值 (30 分钟)

15m 是 App 的最细窗口。把 12:00~15:00 切成 12 个 15m 窗口，
对每个窗口做 T 扫描，找出能让自算值**精确**等于 App 的 T 集合：

| 15m 窗口 | App 大单净流入 | 精确匹配的 T | 唯一？ |
|---|---|---|---|
| 12:00~12:15 | | | |
| …… | | | |

**观察**：T 是什么数的倍数？序列是平稳的还是台阶状的？

## 任务 4：提出公式假设 (20 分钟)

现在把 T 序列和数据对时间轴，问三个问题：

1. T 变化的时刻，和哪个时间边界对齐？
2. T 的取值粒度是多少？
3. T 和"最近一段时间的什么统计量"相关？
   （提示：把 [b−2h, b) 的 quote 做个 P90 看看）

写出你的公式假设：`T(b) = f(?)`。

## 任务 5：独立样本交叉验证 (15 分钟)
